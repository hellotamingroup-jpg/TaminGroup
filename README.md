# TAMIN GROUP: официальный сайт

Статический сайт без сборки. Файлы: `index.html`, `style.css`, `script.js`.
Файл `worker.js` не входит в сайт, это серверная функция для заявок в Telegram.

## Запуск на компьютере

Откройте `index.html` двойным щелчком. Нужен интернет для шрифтов.

## Публикация

1. GitHub Pages: загрузите три файла в репозиторий, в настройках включите Pages.
2. Или Netlify / Cloudflare Pages: перетащите папку с тремя файлами в панель.

## Что заменить в тексте

- Проекты, направления, план на 2027 и блок «Факты» в `index.html`: сейчас там примерные тексты.
- Год в подвале.
- Соцсети: добавьте ссылки в раздел «Контакты».

## Форма: как она работает

Режим по умолчанию. `FORM_ENDPOINT` в `script.js` пустой. Форма открывает
почтовую программу с готовым письмом на hello.tamingroup@gmail.com и копирует текст.
Ничего настраивать не нужно.

Режим «заявки в Telegram-бот». Нужно один раз настроить Worker:

1. В Telegram откройте @BotFather, возьмите токен бота @Tamin_Group_bot
   (команда /token или /mybots). Никому не показывайте токен.
2. Напишите вашему боту любое сообщение, затем откройте в браузере:
   https://api.telegram.org/bot<ТОКЕН>/getUpdates
   В ответе найдите "chat":{"id":ЧИСЛО}. Это CHAT_ID.
3. Зарегистрируйтесь на cloudflare.com, создайте Worker и вставьте код из `worker.js`.
4. В настройках Worker добавьте переменные (секреты):
   BOT_TOKEN = токен из шага 1
   CHAT_ID = число из шага 2
   ALLOWED_ORIGIN = адрес вашего сайта, например https://tamin.example
5. Скопируйте адрес Worker и вставьте в `script.js`:
   var FORM_ENDPOINT = "https://ваш-worker.workers.dev";
6. Опубликуйте сайт заново и отправьте тестовую заявку. Она придёт в бота.

Если токен случайно попал в чат или в код сайта, замените его через @BotFather
(команда /revoke) и обновите BOT_TOKEN в настройках Worker.

## Оформление

Цвета и шрифты заданы переменными в начале `style.css` (блок `:root`).
Тёмная тема включается автоматически, если она выбрана в системе.
