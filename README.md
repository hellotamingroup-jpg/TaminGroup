# TAMIN GROUP: официальный сайт

Одностраничный сайт технологической группы TAMIN GROUP. Слоган: **WE BUILD WHAT'S NEXT.**
Технологии без сборщиков и фреймворков: обычные HTML, CSS и JavaScript.

## Структура

```
tamin-site/
├── index.html   # разметка и тексты всех разделов
├── style.css    # оформление, цвета и шрифты, светлая и тёмная темы
├── script.js    # форма обратной связи и кнопка копирования почты
└── README.md
```

Разделы на странице: главный экран, О компании, Направления, Проекты, TAMIN Innovation, Польза для бизнеса, План на 2027 год, Контакты.

## Запуск на своём компьютере

Сайт можно открыть двойным щелчком по `index.html`. Для проверки через локальный сервер:

```
cd tamin-site
python3 -m http.server 8000
```

Затем откройте http://localhost:8000. Шрифты подгружаются из Google Fonts, поэтому нужен интернет.

## Что заменить перед публикацией

В текстах есть примерные данные. Замените их реальными:

- **Проекты** (раздел `id="projects"` в `index.html`): названия, описания и стадии. Стадия задаётся блоком `<div class="stage">`: у каждого заполненного отрезка стоит класс `on`.
- **Направления** (раздел `id="directions"`): описания и теги.
- **План на 2027** (раздел `id="2027"`): задачи по кварталам.
- **Блок «Факты»** в разделе «О компании»: цифры и формулировки.
- **Год** в подвале страницы.
- **Соцсети**: ссылок на них пока нет, добавьте их в раздел «Контакты» или в подвал.

Почта компании `hello.tamingroup@gmail.com` указана в `index.html` (ссылка в разделе «Контакты») и в `script.js` (константа `EMAIL`). При смене адреса исправьте оба файла.

## Как включить отправку формы

Форма отправляет сообщения через внешний сервис приёма форм. Пример с Formspree:

1. Зарегистрируйтесь на https://formspree.io, указав почту компании.
2. Создайте форму и скопируйте её адрес вида `https://formspree.io/f/xxxxxxxx`.
3. Откройте `script.js` и вставьте адрес в константу:

   ```js
   var FORM_ENDPOINT = "https://formspree.io/f/xxxxxxxx";
   ```

4. Отправьте тестовое сообщение с опубликованного сайта и убедитесь, что письмо пришло. При первой отправке сервис может попросить подтвердить почту.

Пока `FORM_ENDPOINT` пустой, форма ничего не отправляет: она копирует текст сообщения и просит отправить его на почту вручную. Вместо Formspree подойдёт любой сервис, который принимает JSON методом POST и пересылает его на почту (например, Web3Forms или Getform), но тогда проверьте формат полей в его документации.

## Публикация

Сайт статический, подойдёт любой хостинг:

- **GitHub Pages**: загрузите три файла в репозиторий, в настройках включите Pages для основной ветки.
- **Netlify** или **Cloudflare Pages**: перетащите папку `tamin-site` в панель управления.
- **Свой хостинг**: скопируйте файлы в корень сайта.

## Настройка оформления

Все цвета и шрифты заданы переменными в начале `style.css`, в блоке `:root`:

- `--accent`: основной акцентный цвет (кобальтовый синий);
- `--bg`, `--surface`, `--tint`: фоны страницы, карточек и подсвеченных блоков;
- `--ink`, `--muted`, `--line`: цвет текста, второстепенного текста и линий;
- `--font-display`, `--font-body`, `--font-mono`: шрифты (Unbounded, Onest, JetBrains Mono).

Тёмная тема включается автоматически, если она выбрана в системе. Чтобы изменить цвета тёмной темы, правьте два блока ниже `:root`: `@media (prefers-color-scheme: dark)` и `:root[data-theme="dark"]`. Значения в них должны совпадать.

Если захотите сменить шрифты, обновите ссылку на Google Fonts в `<head>` файла `index.html` и значения переменных в `style.css`. Выбирайте шрифты с поддержкой кириллицы.
